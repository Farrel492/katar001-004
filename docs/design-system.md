# Design System (awal — disempurnakan di Fase 1)

## Arah
Elegant Futuristic, modern community digital platform. Admin dan publik satu bahasa desain.
Admin: produktivitas dan data. Publik: informasi, kenyamanan, navigasi sederhana.

## Prinsip
- Dark navy / midnight blue sebagai dasar, aksen electric blue dan cyan (violet hemat).
- Glassmorphism dan gradient halus, hanya pada elemen tertentu, bukan semua kartu.
- Hindari neon berlebihan, tampilan ramai, dan kesan template generik.
- Keterbacaan nomor satu: kontras memadai, ukuran huruf publik cukup besar untuk lansia.
- Animasi bermakna, hormati prefers-reduced-motion. Konten inti tidak bergantung pada 3D/WebGL.

## Token (nilai final ditetapkan di Fase 1 dan dicocokkan dengan referensi dashboard)
- Warna: background, surface, border, text, text-muted, primary, accent, success, warning, danger
- Typography: keluarga font sans-serif modern, skala ukuran, bobot
- Spacing, radius, elevation/shadow, durasi dan easing animasi
- Breakpoint: ponsel, tablet, desktop

## Komponen dasar
Button, Card, Input/Textarea/Select, Table (+ mode ponsel), Badge status, Modal, Sidebar, Navbar,
Tabs, Toast, Skeleton/Loading, EmptyState, ErrorState, StatCard.
